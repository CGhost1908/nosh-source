## What's New in Nosh v1.4.1

- **Note Snapshots & Revisions:** Capture point-in-time snapshots of your active notes and roll back to previous revisions anytime with a single click.
- **Cross-Device Note Synchronization:** Seamlessly sync notes across other devices (desktop and mobile) using zero-knowledge authenticated End-to-End Encryption (AES-GCM-256 + HMAC-SHA256) and instantaneous QR pairing.
- **System-Wide Quick Note (`Ctrl+Alt+N`):** Summon a floating, distraction-free quick capture scratchpad from anywhere in Windows with a global hotkey, save with `Ctrl+Enter`, or dismiss with `Escape`.
- **Automated CI/CD Pipeline:** Release installers are now built and packaged automatically via GitHub Actions and Inno Setup 6 on reproducible cloud runners.
- **Shortcut & Runtime Stability:** Hardened global shortcut registration to prevent conflicts across Windows sessions and improved note sync error recovery.
