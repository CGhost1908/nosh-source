2. Description of the Software

Nosh is a lightweight, local-first desktop note and code editor for developers, thinkers, and students. By default, your notes, code snippets, and configuration reside directly on your local device.

The Software also provides optional integrations that connect to external networked systems when invoked by you, including Google Drive cloud backup, public note sharing via Supabase, public media hosting for shared notes via Catbox.moe, cross-device encrypted vault synchronization, and an embedded YouTube companion player.
